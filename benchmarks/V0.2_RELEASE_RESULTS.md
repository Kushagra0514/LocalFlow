## Verification

- 125 unit tests were discovered: 124 passed and one source-tree real-Whisper
  test skipped because those source-tree fixtures were unavailable.
- The packaged real-Whisper smoke test passed with the verified model seed.
- The deterministic feature-level test covered fixed WAV input, raw local
  dictation, cleanup success and connection fallback, valid command dispatch,
  unsafe argument rejection, command connection failure, clipboard policy, and
  a mocked launcher without an external connection.
- ZIP and installed-file scans rejected `.bin`, `.gguf`, `.part`, llama.cpp,
  S1-mini, packaged live configuration, and obsolete notices.
- Silent fresh install, safe legacy TXT migration, existing-INI preservation,
  precise stale-runtime cleanup, config-path discovery, executable launch,
  upgrade, and uninstall passed in isolated workspace directories.
- Adversarial command tests covered paths, URLs, control characters, shell
  separators, unknown tools, malformed/multiple calls, missing applications,
  ambiguous applications, and shutdown boundaries; rejected cases never called
  the launcher.

## Deliberately unmeasured or pending

- No real Groq request was made because it consumes user API usage. The manual
  opt-in command is documented and requires `--confirm-billable`.
- Installer testing used isolated directories under the current Windows user,
  not a separate clean Windows account.
- The matrix ran against the preserved working tree. A clean-checkout rerun and
  release tag remain pending until the work is committed.
- These measurements do not represent older or low-resource hardware.
